# Norbert Mwiseneza · Portfolio

One-page portfolio built with Vite, React, TypeScript, Tailwind CSS and Framer Motion. Deployed on Vercel.

All copy (experience, projects, skills, links) lives in `src/data/content.ts` and mirrors the resume, so update both together.

```bash
npm install
npm run dev     # local dev server
npm run build   # type-check + production build
```
